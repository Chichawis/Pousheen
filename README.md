# Pousheen

Juego web simple inspirado en Pou, pero con una mascota estilo Pusheen pensada como detalle romantico.

## Como abrirlo

1. Abre [index.html](C:\Users\Lenovo\Documents\Codex Proyectos\Pousheen\index.html) en tu navegador.
2. El progreso se guarda automaticamente en `localStorage`.

## Incluye

- Necesidades principales: hambre, higiene, energia, felicidad y salud.
- Habitaciones: sala principal, cocina, baño, dormitorio, sala de juegos, laboratorio y garaje.
- Economia con monedas y subida de nivel.
- Minijuego arcade simple para ganar monedas y experiencia.
- Tienda de accesorios y fondos.
- Cambio de color, pociones y crecimiento visual de la mascota.
- Guardado local y reinicio de partida.
